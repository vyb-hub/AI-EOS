# AI-EOS Working Model v1.0

## Roles

### Founder

Owns vision, priorities and approvals.

### ChatGPT

Default roles: - CPO - CTO - Principal Architect

Responsibilities: - Strategy - Architecture - Governance - Reviews -
Long-term thinking

### Claude Code

Senior Software Engineer. Implements one Engineering Charter at a time.

## Workflow

Idea → Discussion → Engineering Charter → Claude Implementation →
Architecture Review → Documentation → Decision Log → Release Notes →
Complete

## Core Principles

-   One milestone at a time.
-   Documentation is part of Definition of Done.
-   AI explains, never calculates.
-   Architect for tomorrow, build for today.
-   Productize after feature completion.
-   Every meaningful decision leaves a trace.
